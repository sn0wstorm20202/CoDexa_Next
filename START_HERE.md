# 🚀 CoDexa Quick Start Guide

## Prerequisites Checked ✅
- ✅ Node.js and npm installed
- ✅ All dependencies installed
- ✅ Database connected (Neon PostgreSQL)
- ✅ Environment variables configured
- ✅ Prisma schema synced

## Option 1: Quick Start (Recommended)

Run the automated startup script:

```powershell
.\start-dev.ps1
```

This will:
1. Start Inngest Dev Server (background)
2. Start Next.js Dev Server (port 3000)
3. Handle cleanup on Ctrl+C

## Option 2: Manual Start (Two Terminals)

### Terminal 1 - Inngest Dev Server
```powershell
npx inngest-cli@latest dev
```

### Terminal 2 - Next.js Dev Server
```powershell
npm run dev
```

## Access Your Application

- **Builder Interface**: http://localhost:3000/builder
- **Inngest Dashboard**: http://localhost:8288
- **API Routes**: http://localhost:3000/api/*

## Testing the Full Stack

1. Go to http://localhost:3000/builder
2. Enter your streaming website prompt (e.g., "Create a Netflix clone with authentication")
3. Click submit
4. Watch the agent:
   - Create E2B sandbox
   - Generate files
   - Install dependencies
   - Start dev server
5. View the preview in the iframe

## Common Issues & Solutions

### ❌ 404 Error on Preview
**Cause**: Dev server not running
**Solution**: Make sure `npm run dev` is running

### ❌ "Something went wrong" message
**Cause**: Inngest not running or E2B API key invalid
**Solution**: 
- Check Inngest is running: http://localhost:8288
- Verify E2B_API_KEY in `.env`

### ❌ Database connection errors
**Cause**: DATABASE_URL incorrect or Neon DB sleeping
**Solution**: 
- Check DATABASE_URL in `.env`
- Visit your Neon dashboard to wake the database

### ❌ OAuth not working
**Cause**: Not configured in Supabase
**Solution**: See `OAUTH_FIX_GUIDE.md` for setup instructions

## Environment Variables Required

Your `.env` file should have:
- ✅ `DATABASE_URL` - Neon PostgreSQL connection
- ✅ `OPENAI_API_KEY` - OpenAI API key
- ✅ `E2B_API_KEY` - E2B sandbox API key
- ✅ `NEXT_PUBLIC_SUPABASE_URL` - Supabase project URL
- ✅ `NEXT_PUBLIC_SUPABASE_ANON_KEY` - Supabase anon key
- ✅ `INNGEST_SIGNING_KEY` - Auto-generated by Inngest CLI
- ✅ `INNGEST_EVENT_KEY` - Auto-generated by Inngest CLI

## Monitoring Agent Execution

Watch the console logs for:
- `🚀 [AGENT] Starting agent function` - Agent started
- `🧠 [AGENT] Retrieving conversation memory` - Context loaded
- `💾 [AGENT] Attempting to save result` - Saving to database
- `🎉 [AGENT] Agent function completed successfully` - Done!
